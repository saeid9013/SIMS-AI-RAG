# SIMS-AI | دستیار اسناد فنی پتروشیمی

سامانه RAG محلی با رابط فارسی برای جست‌وجو و پاسخ مستند به PDF و Word.

## وضعیت
نسخه اولیه ۰.۱ پیاده‌سازی شده و ۱۸ آزمون خودکار موفق دارد؛ برای بهره‌برداری صنعتی نیازمند ارزیابی با اسناد واقعی و بازبینی متخصص است.
وضعیت آزمون‌ها و انتشار را در [VALIDATION](docs/VALIDATION.md) ببینید.
هیچ سند فنی، رمز یا مدل باینری در این مخزن عمومی ذخیره نمی‌شود.

## هدف نسخه اولیه
- ورود کاربران و نقش مدیر/کاربر؛ ایجاد کاربر فقط توسط مدیر.
- بارگذاری PDF، DOCX و TXT و تبدیل DOC قدیمی از طریق LibreOffice.
- نگهداری شماره صفحه PDF، ترتیب پاراگراف و جداول Word و قطعه‌بندی با همپوشانی.
- جست‌وجوی متنی محلی؛ لایه برداری محلی اختیاری برای جست‌وجوی ترکیبی.
- پاسخ با منابع قابل مشاهده؛ خودداری از تولید پاسخ وقتی شاهدی نیست.
- انتخاب حالت استخراجی، Ollama محلی یا سرویس آنلاین سازگار با Chat Completions توسط مدیر.
- عدم انتقال اطلاعات به سرویس آنلاین تا زمان فعال‌سازی صریح توسط مدیر.

این پروژه از RAG استفاده می‌کند؛ آموزش یا فاین‌تیون مدل جزو نسخه اولیه نیست.

## شروع سریع

```bash
python -m venv .venv
# Activate the virtual environment; see the Persian installation guide.
python -m pip install -r requirements.lock
python -m app.cli create-admin admin
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 1
```

نشانی: http://127.0.0.1:8000 — حالت اولیه استخراج مستقیم است؛ برای پاسخ تولیدی، مدل محلی یا آنلاین را تنظیم کنید.
