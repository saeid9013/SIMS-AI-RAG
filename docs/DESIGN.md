# Design rationale

Requested source: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
Read `.claude/skills/ui-ux-pro-max/SKILL.md` and executed its design-system search for `industrial knowledge dashboard`.
The verified style result is Minimalism & Swiss Style, suited to enterprise dashboards; its navy/slate palette is retained.
The generator also returned a marketing conversion pattern, which is inappropriate for an internal knowledge app and is not used.
See `design-system/sims-ai/MASTER.md` for the original generated guidance.

Product adaptation: Persian RTL, server-rendered pages, local system fonts (no CDN or Google Fonts), navy navigation, light readable document surfaces, clear green action with dark text, visible labels, 44px controls, keyboard focus, reduced motion, loading feedback, separate admin navigation.
The chat must always show provider mode and evidence cards. Word locations must never be labeled as page numbers.
